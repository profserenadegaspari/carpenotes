# Carpe Notes · sito degli studenti

Palestra di italiano e latino per il biennio del liceo, di prof.ssa Serena De Gaspari.

Si entra **solo con il link d'invito** consegnato dalla prof. Teoria, esercizi e soluzioni sono in
`assets/contenuti-cifrati.js`, cifrati: senza la chiave contenuta nel link non sono leggibili.

## Per la prof: aggiornare i contenuti
1. Nell'area docente (sul tuo computer) vai in **Pubblica e impostazioni** e premi **Scarica per il sito online (cifrato)**.
2. Qui su GitHub apri la cartella `assets`, scegli **Add file › Upload files** e trascina `contenuti-cifrati.js`.
3. Premi **Commit changes**. Dopo un paio di minuti il sito è aggiornato.

L'area docente e il file `contenuti.js` normale non vanno mai caricati qui.
