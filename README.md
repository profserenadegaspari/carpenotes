# Carpe Notes · sito degli studenti

Palestra di italiano e latino per il biennio del liceo, di prof.ssa Serena De Gaspari.

Si entra **solo con il link d'invito** consegnato dalla prof. Teoria, esercizi e soluzioni sono in
`assets/contenuti-cifrati.js`, cifrati: senza la chiave contenuta nel link non sono leggibili.

## Per la prof: aggiornare i contenuti
Nell'area docente (sul tuo computer) vai in **Pubblica e impostazioni** e premi **Pubblica sul sito**.
La prima volta ti chiede di collegare GitHub con una chiave di accesso (fine-grained token, solo per questo
repository, permesso «Contents: Read and write»).

Senza collegare GitHub: premi **Scarica per il sito online (cifrato)**, poi qui apri la cartella `assets`,
scegli **Add file › Upload files**, trascina `contenuti-cifrati.js` e premi **Commit changes**.

L'area docente e il file `contenuti.js` normale non vanno mai caricati qui.

## Font
I caratteri (Bricolage Grotesque e Nunito) sono in `assets/fonts/`, ospitati qui: il sito non li chiede a Google Fonts,
quindi aprendo le pagine nessun dato degli studenti arriva a server esterni. Licenza SIL Open Font License 1.1 (file `OFL-*.txt`).
